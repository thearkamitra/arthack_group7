# Spatial reflection

The project is changing from the Borrowed Eyes mesh experiment to an AI-guided,
immersive reflection experience. Active development takes place on `master`.

The initial target is a large 2D image on a Mac, followed by Meta Quest 2/3.
Conversation and selected regions will progressively define the scene. Garmin
Venu 4 heart-rate broadcasting is an optional expressive input.

The previous implementation is preserved in Git history at `8bfaa19`.
Source images, the existing local Python environment, and the pinned Auto-MIA
submodule are retained. Auto-MIA is not required by the new prototype.
